    两个 Embedding 的点积

    输出 Shape []

    点积把两个向量对应位置的分量相乘，再把这些贡献加起来。同号分量产生正贡献，异号分量产生负贡献；整体数值可表示一种匹配程度，也会受到向量长度影响。当前向量是人工设定的教学数字，没有经过训练，结果不是模型学出的词义相似概率。

    标量 Shape []

    数学

    a · b = Σ a[i] × b[i]。这里的每个乘积，表示这两个向量在同一个分量位置上的共同贡献。

    Shape

    两个 Shape 为 [3] 的向量产生三个乘积；求和后只剩一个数字，Shape 写作 []，表示没有维度轴，不是空数组。

    对应的核心代码

    let sum = 0;
for (let i = 0; i < a.length; i += 1) {
  sum += a[i] * b[i];
}

    循环每次计算一个分量的贡献，再把它加到累计和中。页面只把结果格式化到最多 6 位小数；计算值本身没有预先舍入。
