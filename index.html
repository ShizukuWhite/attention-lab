    数学

    a · b = Σ a[i] × b[i]。这里的每个乘积，表示这两个向量在同一个分量位置上的共同贡献。

    Shape

    两个 Shape 为 [3] 的向量产生三个乘积；求和后只剩一个数字，Shape 写作 []，表示没有维度轴，不是空数组。

    对应的核心代码

    let sum = 0;
for (let i = 0; i < a.length; i += 1) {
  sum += a[i] * b[i];
}

    循环每次计算一个分量的贡献，再把它加到累计和中。页面只把结果格式化到最多 6 位小数；计算值本身没有预先舍入。

    数学

    Shape

    对应的核心代码

    const xRow = X.matrix[i];
const wColumn = W.matrix.map(row => row[j]);
const steps = dotProductSteps(xRow, wColumn);

    本阶段的计算复用已经看过的点积步骤；矩阵乘法只是为每个输出格选择一行和一列。

    直觉

    每个 Query 都和每个 Key 位置比较一次，因此 N 个位置形成 N×N 个分数。这里的固定教学数字不表示词义相似程度。

    数学

    S[i,j] = qᵢ · kⱼ = Σₜ Q[i,t] × K[j,t]。它是有方向的 Query-Key 配对；一般 S[i,j] ≠ S[j,i]。

    Shape

    Q [N, 2] × Kᵀ [2, N] → S [N, N]。中间的分量 t 被求和，保留 Query 行和 Key 列；单个格子的点积 Shape 是 []。

    核心代码

    const KT = transposeMatrix(K);
const S = multiplyMatrices(Q, KT);

    页面沿用矩阵乘法和点积追踪；计算保留完整精度，只在显示时最多保留 6 位小数。此处尚未做缩放、Softmax 或 V 加权求和。

    V 保留在 Phase 4 的投影表中用于后续学习；它不参与当前的 QKᵀ 分数计算。

    本步要点

    位置配对 · 原始分数 · N × N

    固定投影产生 Q、K、V；对每个 Query 位置和 Key 位置做一次点积，得到有方向的原始分数 S = QKᵀ。V 保留展示但暂不参与计算。

    Q [N, 2] × Kᵀ [2, N] → S [N, N]
