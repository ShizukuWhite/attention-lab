    这些向量由人工设定，用于观察数据形状，不来自训练模型。未知 Token 使用零向量占位；相同的零向量不代表词义相同。

    本步要点

    一个 Token，三个数字

    直觉上，Embedding 就是为每个 Token 查出一个向量。数学上可写成 X[i] = embedding(tokens[i])。每个向量有 3 个分量，Shape 是 [3]；把 N 个向量按行排列后，矩阵 Shape 是 [N, 3]。N 决定行数，d_model 决定列数。
